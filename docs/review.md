# Conventional comments

## Format

```
<label> [decorations]: <subject>

[discussion]
```

## Labels

- **praise**
- **thought**/**question**/**note**: non-blocking
- **nitpick**/**quibble**: preference based, non-blocking
- **suggestion**/**polish**: (non-)blocking
- **typo**/**chore**/**todo**: blocking
- **issue**/**critical**: blocking

## decorations

- **(blocking)**/**(non-blocking)**: from reviewer's perspective
- **(if-minor)**: from author's perspective
- **(security)**/**(test)**: sec issue/missing test/...

## Examples

> **suggestion (test,if-minor):** It looks like we're missing some unit test
> coverage for the cat's current status.
